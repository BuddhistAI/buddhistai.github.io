# buddhistai.github.io

The BuddhistAI homepage, served by GitHub Pages at https://buddhistai.github.io/.

`index.html` is one self-contained page. Its design source is the homepage mockup; scores on it are the real results from [buddhist-benchmarks](https://github.com/BuddhistAI/buddhist-benchmarks). When results change, update the numbers here too (or, later, read them from the leaderboard data).
