How to read it

  1. Score is the task's headline metric, 0 to 1. Here: how well the outline matches the reference.
  2. Gain is what the skill adds over the same model with a plain prompt.
  3. Cost is the API bill for 100 pages. Best value is the top score at 20% of the top cost or less.
  4. Only compare rows on the same benchmark version.

Read two answers. Pick the better one.

Some work has no single right answer. Translators and teachers vote blind between two answers, from a model on its own or a model with a skill, and the votes become a ranking for each task and language.

Workflows

How Buddhist projects use AI

Short guides that chain tasks together, written with the teams who do this work. Green steps have a measured skill today.

Prepare a commentary for translation

text-cleanup→toc-extraction→segmentation→text-commentary-alignment

From an OCR file to a structured, segmented source with its outline.

Build a project glossary

text-translation-alignment→term-extraction→entity-extraction

Collect renderings from past translations into one reviewed glossary.

Review a draft translation

translation→citation-mapping→translation-review

Check a draft against source, glossary and style guide before an editor sees it.

Contribute

Paste a link. We test it for you.

Skills and benchmarks here are open source and built together. Anyone can add a skill, a model, a test set, or a fix to any of them. Paste a link to get started; evaluation is free, paid by a sponsor.

Today your link opens a GitHub issue and a maintainer runs the evaluation. Automatic checks are coming.

A folder with a SKILL.md is enough. Any language, any model.

      Every skill's task repo keeps all its variants. Fork the top one, change it, paste your fork. If it scores higher, it becomes the main skill.

      Grow a benchmark

      Add the edge cases your team runs into, fix a wrong answer, or publish your own set. Competing sets from different groups are all kept.

      Read two answers and pick the better one. Votes from translators and teachers rank the open-ended tasks.
